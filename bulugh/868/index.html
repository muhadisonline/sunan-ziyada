كتاب الحج

وَعَنْ اِبْنِ عَبَّاسٍ وَأُسَامَةَ بْنِ زَيْدٍ رَضِيَ اَللَّهُ عَنْهُمْ قَالَا: { لَمْ يَزَلِ اَلنَّبِيُّ ‏- صلى الله عليه وسلم ‏-يُلَبِّي حَتَّى رَمَى جَمْرَةَ اَلْعَقَبَةِ } رَوَاهُ اَلْبُخَارِيُّ.‏ 1‏ .‏‏1 ‏- صحيح.‏ رواه البخاري ( 3 / 532 / فتح )‏.‏
