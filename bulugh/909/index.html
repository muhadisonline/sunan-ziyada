الحديث 909

كتاب البيوع

وَعَنْ أَبِي هُرَيْرَةَ ‏- رضى الله عنه ‏- قَالَ: { نَهَى رَسُولُ اَللَّهِ ‏- صلى الله عليه وسلم ‏-عَنْ بَيْعِ اَلْحَصَاةِ, وَعَنْ بَيْعِ اَلْغَرَرِ } رَوَاهُ مُسْلِمٌ 1‏ .‏‏1 ‏- صحيح.‏ رواه مسلم ( 1513 )‏.‏

Narrated Abu Hurairah (RA):

Allah's Messenger (ﷺ) forbade a transaction determined by throwing stones, and the transaction which involves some uncertainty (or cheating). .
