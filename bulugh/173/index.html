كتاب الطهارة

وَعَنْ عَائِشَةَ رَضِيَ اَللَّهُ عَنْهَا قَالَتْ: { كَانَ رَسُولُ اَللَّهِ ‏- صلى الله عليه وسلم ‏-يَأْمُرُنِي فَأَتَّزِرُ, فَيُبَاشِرُنِي وَأَنَا حَائِضٌ } مُتَّفَقٌ عَلَيْه ِ 1‏ .‏‏1 ‏- صحيح.‏ رواه البخاري (300)‏، ومسلم (293)‏، واللفظ للبخاري.‏
ترجمة sunnah.com، ليست من لفظ الكتاب

Narrated `A'ishah (RAA):

When I was menstruating, the Prophet saws would order me to wrap myself up (with an Izar, which is a dress worn below the waist) and would start fondling me. Reported by Al-Bukhari and Muslim.
